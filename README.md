# Digital Twin Engine Dashboard

Interactive WebGL-based digital twin simulation built with Unity.

## Features

* Real-time engine telemetry UI
* Interactive 3D engine visualization
* Diagnostic dashboard system
* WebGL deployment support

## Tech Stack

* Unity WebGL
* C#
* Custom UI system
* Vercel deployment

## Run Locally

```bash
npx serve .
```

Then open:
`http://localhost:3000`
